# 美学光伏瓦Pro屋面排布

交付水平投影总平面、各坡展开排布（SVG/DXF）、瓦片数量及容量CSV、原生Blender与GLB、PNG效果图、含气象依据的离线HTML报告。先读图确认实际屋面，重复几何和统计由本技能程序执行；不承诺任意DWG都能无判读自动重建。

## 固定规则

- 当前产品仅 **BIAC14B-70，70 W/片，1240×390×6.2 mm**。名称中的158不是功率。
- 横向有效1220 mm，沿坡340 mm；左右20 mm、上下50 mm搭接，不随坡度改变。
- **厂家允许坡度严格大于12°**。不能把12°判为合格、套用教学30°或改变建筑坡度；未给厂家最大坡度。
- 所有排布必须使用**坡面展开实长**。水平图只作定位/总平面展示；已给斜长不得再除cos。按局部正交坡面坐标构建，不用投影面积反推片数。
- 相邻排错开610 mm，坡下向坡上铺；右瓦搭在左瓦右侧20 mm垫条。4×7只是回归样例，不能硬编码真实项目排数。
- 发电整瓦完整使用；非发电整配瓦1240×390、半配瓦630×390默认可裁切，可用于斜边、天窗、烟囱周边。**无四分之一配瓦**，半配瓦不能按35 W计。清单为占位原片估算，不自动优化余料复用。
- 每片发电整瓦4孔、4只已确认折回钩抑风扣、4枚自攻螺丝。钩朝坡下，上瓦下缘进入下瓦扣槽。每片两条底宽5 mm/高2.5 mm的上沿半圆胶条，右侧20 mm宽垫条。固定孔、扣件尺寸及垫条厚度为照片比例示意，不能冒充加工图。
- 收口依现有安装说明书。边瓦边界留≥65 mm；高低跨按靠墙泛水处理。天沟顺水条离中心≥100 mm不是所有瓦片通用退距。旧书3扣规定被用户4孔4扣确认覆盖。未确定的配件尺寸仅列延米/待核，不套三曲瓦参数。
- 容量仅按实际发电瓦×0.07 kWp统计；配瓦、备料、建筑数量不得误乘。预测按实际项目地点、各坡朝向/坡度与气象计算，默认不增加并网、储能、逆变器选型或经济收益。
- 系统效率统一 **0.88（88%）**，替换旧14%系统损耗。先取得未扣综合系统损耗的基准发电量，再乘0.88一次；月量与年量采用同一口径。PVGIS请求`loss=0`，本地应用0.88；已知额外遮挡单独折减，不能重复扣除已有损耗。离线年比发电量必须注明`before_system_losses`基准，不能把已扣损耗净值直接再乘0.88。

参数来源、安装节点页码与优先级见 [references/product-rules.md](references/product-rules.md)。

## 工作流程

1. 确认图名/栋数、北向、屋顶最高层、檐口与脊线、投影尺寸/标高/坡比、洞口及用户发电区域。PDF先渲染相关页结合平面、立面和剖面核对。DWG/DXF读 [references/drawing-input.md](references/drawing-input.md) 并运行 `scripts/inspect_drawing.py`，不改原图。
2. 将识别结果按 [references/input-schema.md](references/input-schema.md) 写入项目JSON。每坡独立展开，公共脊在同一世界坐标闭合；高低跨不可合并成一个平面。图纸已明确的信息不用重复询问。缺失会改变片数/坡向/节点时集中问具体疑点，同时推进独立工作；示例可采用有依据的选图规则并在成果列明冲突。
3. 在新成果版本目录运行：

   ```sh
   <skill>/.venv/bin/python <skill>/scripts/run_project.py --project /绝对路径/project.json --output /绝对路径/成果V1 --render
   ```

   `<skill>`为本文件所在目录。无环境时用可用Python3运行 `scripts/setup.py`，仅安装本技能独立环境。Blender可用`--blender`指定；保留原始图纸和旧成果，非空目录拒绝写入。合成回归输入 [references/example-project.json](references/example-project.json) 不能替代实际项目图纸。
4. 发电量按 [references/energy-method.md](references/energy-method.md)。用户给地点时可查有出处的坐标；村级/城市级代表点必须明示，不能伪装建筑定位。北针无数字角度时说明图形量取/正南场景假设，必要时确认。优先PVGIS逐坡估算；无PAN也可输出方案级结果。近遮挡未模拟必须明说，气象API失败不能当零或悄悄换城市。缺地点不阻止排布及容量，发电量暂列缺项。
5. 核对所有2D、3D、统计都来自同一`layout.json`。完整PV足迹全部位于指定发电区、避开洞口；铺瓦区域覆盖校验通过；整/半配瓦分类一致；容量=真实PV计数×0.07；共边不重复。打开PNG与HTML，核验坡面高差、收口、错缝、Logo完整及数据。月量与年量一致，保留气象原始响应。代码变更运行 `scripts/test_layout.py` 与 `scripts/test_energy.py`；一般项目不重复所有代码回归。
6. 保存本地成果及ZIP，技能本体另可打包（排除`.venv`和缓存）。最后给可打开的报告/图纸/模型与效果图，简述容量、发电量方法和真正未核实项。

## 范围边界

多块平面屋面可用独立多边形建模。曲率连续屋面、变坡、无尺寸图纸、未知泛水节点需要明确识别，不把教学网格用作施工实测。图上未画障碍物不等于竣工无遮挡。现有算法按起排线错缝，不声称全局最大装机；需要容量与对称外观比较时调整起排方案并比较结果。
