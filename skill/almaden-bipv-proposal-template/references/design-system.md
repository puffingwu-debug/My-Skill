# 视觉系统规范

本文件是版式的唯一事实来源。`scripts/deck_kit.py` 顶部的常量与本文一一对应；
两者不一致时以本文为准并同步改代码。

## 1. 画布与栅格

| 项 | 值 |
|---|---|
| 画布 | 13.3333 × 7.5 in（16:9） |
| 左右边距 `M` | 0.62 in |
| 正文宽 `CW` | 12.0933 in |
| 页眉起始 `HEAD_Y` | 0.50 in |
| 正文首行 `BODY_Y` | 1.72 in |
| 页脚基线 `FOOT_Y` | 6.98 in |
| 正文安全下沿 `BODY_B` | 6.78 in |

**正文任何元素不得越过 6.88 in**（页脚细分隔线位置）。`check_deck.py` 按此判定
`PAST-FOOTER`。

常用列宽分法（间距经验值 0.20–0.34 in）：
- 两栏：左 6.35–6.40 / 右余量
- 三栏：`(CW − 2×0.30) / 3` = 3.83
- 四栏：`(CW − 3×0.22) / 4` = 2.86
- 左图右表：图 4.05–5.30，表取余量
- 表格 + 右侧栏：侧栏 3.05–3.25

## 2. 配色

| 名称 | 值 | 用途 |
|---|---|---|
| `ORANGE` | `#F45918` | 品牌橙：色条、编号、关键数字、圆点、页脚页码 |
| `ORANGE_DK` | `#C9420C` | 橙底上的文字 |
| `ORANGE_LT` | `#FDECE3` | 橙色提示框底色 |
| `ORANGE_BD` | `#F6C9AE` | 橙色提示框描边 |
| `INK` | `#1A1A1A` | 主文字；表头填充；说明面板底色 |
| `GRAY` | `#5F6B76` | 正文次要文字、图注 |
| `GRAY_LT` | `#8B96A1` | 页脚、更弱的说明 |
| `LINE` | `#DDE2E6` | 分隔线、卡片描边、表格线 |
| `BG_SOFT` | `#F4F6F7` | 浅灰卡片底、斑马纹 |
| `BG_CARD` | `#FAFBFD` | 目录卡等更浅的底 |
| `DARK_BG` | `#161618` | 封面、章节页、封底 |

规则：
- **橙色是强调色，不是背景色**。单页橙色面积宜 < 10%，大面积用浅灰或深黑。
- 深色底仅出现在封面 / 章节页 / 封底，正文页一律白底。
- 同一页内的强调色不超过两种（通常 `ORANGE` + `INK`）。

## 3. 字体与字号

中文 `微软雅黑`，西文 `Arial`。**每个 run 必须同时写 `a:latin` 和 `a:ea`**
（`deck_kit._set_ea` 已封装）。只写 `a:latin` 时 PowerPoint 会让中文走默认宋体。

| 角色 | 字号 | 字重 | 颜色 |
|---|---|---|---|
| 封面主标题 | 42 | Bold | 白 |
| 章节页大标题 | 36 | Bold | 白 |
| 章节页超大编号 | 88 | Bold | `#2E3135`（近黑，压暗） |
| 封底标语 | 32 | Bold | 白 |
| 页面主标题 | 23 | Bold | `INK` |
| KPI 大数字 | 25–27 | Bold | `INK` |
| 小标题 / 卡片标题 | 11–15 | Bold | `INK` |
| 正文 / 列表 | 9.5–10.5 | Regular | `GRAY` |
| 图注、页脚 | 8.5–9.5 | Regular | `GRAY_LT` |
| 页眉栏目名 | 10.5 | Bold | `ORANGE` |

行距：正文 1.40–1.42，标题 1.0–1.16，表格 1.12。
字距不做调整；西文与数字前后留半角空格（如 `42.64 kWp`）。

## 4. 固定构件

**页眉**（`header()`）
```
橙色竖条 0.055 × 0.36 in @ (0.62, 0.545)
栏目名 @ (0.82, 0.50)        10.5pt Bold 橙
主标题 @ (0.82, 0.735)       23pt Bold INK
副标题 @ (0.62, 1.30)        11.5pt GRAY   —— 无副标题时改画细分隔线
```

**页脚**（`footer()`）
```
细分隔线 12.0933 × 0.010 in @ (0.62, 6.88)
左标签 @ (0.62, 7.02)        8.5pt  GRAY_LT
右页码 @ (11.81, 7.00)       11pt Bold 橙，两位数字
```
封面不编号；目录页为 01，之后按出现顺序连续编号（章节页也占号）。

**章节页**（`divider()`）：全深底 + 左侧橙条（0.14 宽 + 0.05 深橙），
超大编号 88pt，英文栏目名 11pt 橙，中文标题 36pt 白，说明 12pt 灰，
底部最多 3 个要点小卡（宽 3.05，间距 3.35），右上角 `logo_light`。

**表格**（`add_table()`）：表头 `INK` 底白字，正文行白 / `BG_SOFT` 斑马纹，
单元格内边距 0.09/0.07 in，垂直居中，四边 0.75pt 线。
行高参考：紧凑 0.285–0.335，常规 0.365–0.415，宽松 0.52–0.545。

**图片卡**（`img_card()`）：白底 + `LINE` 描边 + 内边距 0.10 in，
图注条高 0.30 in 居中 9.5pt `GRAY`。图片一律等比缩放（`pic_fit`），**不得拉伸**。

## 5. 容差与已知坑

- **表格会自动撑高。** 行高只是最小值；单元格文字换行后 PowerPoint 会把表格变高，
  因此表格下方元素必须留 ≥ 0.20 in 余量，且行高与实际行数要匹配。
  估算公式：`表高 ≈ head_h + (行数 − 1) × row_h`。
- **文本框高度可溢出。** `textbox()` 设了 `MSO_AUTO_SIZE.NONE`，
  文本框只是占位，文字会自然向下溢出。所以 `h` 给近似值即可，
  但**必须**用 `check_deck.py` 复核是否压到下方元素。
- **中文字宽 ≈ 1 em。** `check_deck.py` 据此估算换行，与 PowerPoint 实测误差在 ±1 行内。
- **单元格线序。** `a:tcPr` 的子元素必须按 schema 顺序
  （`lnL, lnR, lnT, lnB → 填充 → headers → extLst`）；
  `deck_kit._cell_border` 已做重排，手写 XML 时不要打乱，否则部分渲染器会整篇拒绝解析。
- **图片路径**按 JSON 所在目录解析，相对路径不要以 `/` 开头。
- **视频必须内嵌。** `add_movie()` 生成 `p14:media` 内嵌关系；
  若 rels 里出现 `TargetMode="External"`，换机后无法播放。
