# 项目 JSON 字段说明

顶层四个键：`meta`、`cover_stats`、`agenda`、`sections`、`closing`。
除 `meta.title_lines` 与 `sections` 外都可省略（省掉的部件不会出现在成稿里）。

图片、视频路径**相对于该 JSON 文件所在目录**解析；缺失会直接报错并给出解析后的绝对路径。

---

## meta

| 字段 | 必填 | 说明 |
|---|---|---|
| `project_name` | ✔ | 项目名，用于默认页脚与默认主标题 |
| `title_lines` | ✔ | 封面主标题，数组，每项一行（2 行最佳） |
| `subtitle` | | 封面副标题；也作为封底默认副标题 |
| `eyebrow` | | 封面主标题上方的小字，默认 `SOLUTION PROPOSAL  ·  方案说明书` |
| `date` | | 封面右下角，如 `2026.09` |
| `version` | | 成果版本，显示为 `成果版本 V1` |
| `footer_label` | | 页脚左侧文字，默认 `{project_name} · BIPV 项目建议书` |
| `cover_bg` | | 封面背景图；建议 16:9、已做暗化处理（见下） |
| `closing_bg` | | 封底背景图 |

**封面／封底背景图要求**：左侧约 45% 区域需要足够暗以承载白字。
若直接用现场照片，先做「降饱和 + 压暗 + 左暗右亮渐变」，否则文字读不出来。

---

## cover_stats

封面底部的关键数字条，**最多 4 个**（建议 3 个）。

```json
"cover_stats": [
  { "value": "42.64", "unit": "kWp", "label": "直流装机容量" },
  { "value": "1,066", "unit": "片",   "label": "完整发电瓦" },
  { "value": "39,883","unit": "kWh",  "label": "年发电量估算" }
]
```
第一个的色条为橙色，其余为深灰。数字里带千分位逗号。

---

## agenda

```json
"agenda": {
  "kicker": "CONTENTS",
  "title": "目录",
  "sub": "本说明书依据…编制",
  "items": [ { "num":"01", "title":"项目概况", "desc":"一句话说明" } ]
}
```
`items` 最多渲染 6 个（3 列 × 2 行）。多于 6 个会被截断。

---

## sections

章节数组。每个章节自动生成一张深色章节页（除非 `divider: false`），
页码在章节页与内容页之间连续编号。

| 字段 | 说明 |
|---|---|
| `num` | 章节号，如 `"01"` |
| `title` | 章节中文名 |
| `en` | 章节英文名（章节页大字上方） |
| `desc` | 章节页说明句 |
| `chips` | 章节页底部要点小卡，最多 3 个 |
| `kicker` | 内容页页眉的栏目名，默认 `"{num}  {title}"` |
| `divider` | `false` 则不生成章节页 |
| `slides` | 该章节的内容页数组，每页一个 `type` |

---

## 页码约定

封面不编号；目录页 = 01；其后按生成顺序连续编号，**章节页也占一个号**。
所以「目录 01 → 章节页 02 → 首个内容页 03」。
页数会随 `slides` 数量自动变化，不用手写。

---

## 内容纪律（写 JSON 时请遵守）

这些不是格式要求，是这套模板被反复强调的口径。违反会让建议书失去可信度：

1. **容量只算完整发电瓦**：`kWp = 完整瓦片数 × 单片功率 ÷ 1000`。
   备料、配瓦、旧图纸上的平面组件都不能计进来。
2. **未确认的东西写"待定"**：型号未定的收口件只给延米，不要折算片数。
3. **发电量必须交代清楚**：气象来源与年份、系统损耗、折减系数及其应用次数、
   未模拟的因素。同一个折减系数**不能乘两次**（写清"已应用，不重复折减"）。
4. **方向要说清**：图上方向 ≠ 地理北向。地理北向未核定时必须写明。
5. **有歧义就并列**：标高／范围存在两种解释时，写明本版采用哪一种，
   并把另一种放进「设计条件与后续事项」。
6. **加范围限定**：标题里尽量写清不含什么，例如
   `装机容量与材料清单(不含下面钢结构部分以及挂瓦条顺水条)`。

## 最小可用示例

```json
{
  "meta": {
    "project_name": "XX 园区屋顶",
    "title_lines": ["XX 园区", "曲面光伏瓦屋面方案"],
    "subtitle": "Almaden BHAC40R-40 曲面光伏瓦 · 排布与容量",
    "date": "2026.10",
    "version": "V1",
    "cover_bg": "images/cover_bg.jpg"
  },
  "cover_stats": [
    { "value": "42.64", "unit": "kWp", "label": "直流装机容量" }
  ],
  "agenda": {
    "items": [
      { "num": "01", "title": "项目概况", "desc": "屋面条件与设计范围" },
      { "num": "02", "title": "产品介绍", "desc": "曲面光伏瓦规格" }
    ]
  },
  "sections": [
    {
      "num": "01", "title": "项目概况", "en": "PROJECT OVERVIEW",
      "desc": "屋面条件与设计范围", "chips": ["装机 42.64 kWp"],
      "slides": [
        { "type": "facts_hero",
          "title": "项目概况与建设内容",
          "table": { "head": ["项目","内容"], "weights": [1,3],
                     "rows": [["装机容量","42.64 kWp"]] },
          "hero": { "image": "images/hero.jpg", "caption": "整体轴测" },
          "stats": [ { "value":"42.64","unit":"kWp","label":"装机容量" } ] }
      ]
    }
  ]
}
```

完整可运行示例见 [../examples/东江阴变电站.json](../examples/东江阴变电站.json)
（30 页，覆盖全部 18 种版式中的 17 种）。

## 常见报错

| 报错 | 原因 |
|---|---|
| `图片不存在：xxx（解析为 /abs/path）` | 相对路径没写对，或图片没生成 |
| `未知版式 type="xxx"。可用：[...]` | `type` 拼错，或该版式尚未注册进 `ARCHETYPES` |
| `未知颜色名 "xxx"` | 颜色字段只能写 `deck_kit` 调色板里的名称 |
| `IndexError: row index [N] out of range` | 表格 `row_h`/`head_h` 与行数不匹配（通常是把 `head` 的列数当成了表头行数） |
