# 三曲瓦屋面排布

交付总平面与各坡展开图（SVG/DXF）、功能瓦数量与分坡容量表（CSV）、可编辑 `.blend`、PNG效果图和含发电量依据的HTML报告。图纸理解由智能体完成，重复排布和统计由随附程序完成；不宣称任意DWG无需判读就能自动重建正确屋面。

## 固定产品规则

- 现款 **BHAC40R-40，40 W/片，723×500×41 mm**。旧常州图纸的45 W、33 mm仅作历史节点参考。
- **2026-09-13用户确认：发电瓦、主配瓦横向与正脊瓦沿脊有效模数统一713 mm；沿坡405 mm，也是挂瓦条间隔。** 覆盖旧报价700 mm及413 mm。发电瓦左右搭接10 mm、上下95 mm；主配瓦宽724 mm，左右搭接11 mm；正脊全长750 mm，搭接37 mm。
- 发电瓦保持完整、不可切割。所有配瓦可按两侧、坡顶、斜边及洞口裁切；清单只估算各功能所需原片，不输出切割加工表、裁切数量或余料方案。备料另列，不能加进装机容量。
- 每片发电瓦两处外侧波谷各一只J形抑风扣，钩朝坡下、扣住上瓦下边缘。复用资产的钩形与姿态，不能改成开口朝上的立钩。
- 发电瓦、配瓦灰黑且低光泽；脊瓦有分片和加强筋。天窗贴坡，泛水灰黑且仅小色差。保留完整Almaden标志。
- **默认不考虑并网、不配储能、不做逆变器选型或经济收益。无需PAN文件。** 发电量为方案级近似，列气象出处、损耗、遮挡假设和未校准局限。
- **2026-09-14用户确认：所有最终发电量统一乘0.88（额外12%折减）。** PVGIS及经验净比发电量均在原系统损耗与额外遮挡处理后，由程序逐坡应用一次再汇总；月量、年量、成功小计均已包含该系数。报告须注明已应用，不能在程序输出上再次乘0.88；40 W/片、瓦数和装机容量不变。
- 南北坡是否铺设、指定发电区及容量/外观优先级属于每个项目的业主输入，不能沿用示例南坡设定。已经明确的问题不重复询问。

规格、版本优先级和节点资料见 [references/product-rules.md](references/product-rules.md)。

## 工作流程

1. 核对图纸单位、比例/标注尺寸、边界、坡度/标高、北向、天窗/烟囱/天沟和指定发电区。DWG/DXF先读 [references/drawing-input.md](references/drawing-input.md)，使用 `scripts/inspect_drawing.py`提取图层/文字/尺寸/多边形并结合预览判读。PDF渲染相关页看尺寸。不要把水平投影长度当斜长、图框当屋面、瓦纹当指定PV区域。
2. 按 [references/input-schema.md](references/input-schema.md) 整理项目JSON。各坡用米制局部实长、真实方位及统一世界坐标。缺失项会改变片数、朝向或节点时，指出具体疑点提问，同时推进独立工作。地点缺失只影响发电量，不阻止已知屋面排布。接口示例见 [references/example-project.json](references/example-project.json)，其中尺寸、地点、留带均为演示，不能冒充实际项目。
3. 在新成果版本目录运行：

   ```sh
   <skill>/.venv/bin/python <skill>/scripts/run_project.py --project /绝对路径/project.json --output /绝对路径/成果V1 --render
   ```

   `<skill>`为本SKILL.md所在目录。缺环境时先用可用Python3运行 `scripts/setup.py`，只安装本技能专用环境；Blender默认寻找本机程序，也可传`--blender /绝对路径/Blender`。不改原图或原始产品模型。非空成果目录会拒绝写入，换V2保留旧版。
4. 发电量读 [references/energy-method.md](references/energy-method.md)。优先PVGIS按地点和每坡容量/角度估算，采用通用晶硅/建筑安装近似。网络错误不能当零、不能静默换城市。可用有来源的净年比发电量或明确标注的方案假设；缺月分布只给年量。不得要求并网、储能或PAN资料才能继续。
5. 核验2D、3D和CSV来自同一`layout.json`；PV完整足迹都在指定区域、避开孔洞；容量=片数×0.04；共享脊只计一次；不发电坡无PV。确认模型和两张PNG实际生成，打开PNG/HTML看外观、标志、天窗和表格。核对最终0.88系数只应用一次，月/年按0.01 kWh最大余数平衡舍入；保留气象原响应及折减前基础量。修改排布逻辑时运行 `scripts/test_layout.py`，不必每个项目重复全部代码回归。

## 规则外情形

- 斜脊、封檐、沟瓦采用各自沿线有效长度，不把405或713套到所有配件。封头/三通/四通按节点计；缺当前尺寸则列延米或待定项，不填虚构片数。
- 高低跨、多坡面可拆成平面多边形。程序不自动改变建筑坡度、设计结构或寻找全局最大装机；按业主要求比较起排与留带方案。
- 连续曲率屋面、异型件、未知收口或不可辨尺寸，引用对应图纸部位提出疑点；教学几何不能充当厂家确认加工节点。
- 最后给可打开的报告、图纸、模型和效果图，简述片数、容量、发电量方法及真正未核实的条件。
